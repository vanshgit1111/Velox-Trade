# 📈 VeloxTrade — Indian Stock Market Dashboard

A real-time Nifty 50 stock dashboard built with Vanilla HTML, CSS & JavaScript.


---

## 🛠️ Tech Stack
- HTML, CSS, Vanilla JavaScript
- Twelve Data API (live NSE stock data)
- Chart.js (mood gauge + price charts)

---

## ✨ Features
- 📊 Live Nifty 50 stock cards with ₹ prices and % change
- 🧠 Market Mood Indicator — Fear / Neutral / Greed
- 🔍 Search, Filter and Sort stocks using Array HOFs
- ❤️ Personal Watchlist with virtual portfolio value
- 📰 Latest Indian market news
- 🌙 Dark / Light mode toggle
- 📱 Fully responsive — mobile, tablet, desktop

---

---

## 🚀 How to Run
1. Clone the repo
2. Get a free API key from [twelvedata.com](https://twelvedata.com)
3. Add your key in `api.js`
4. Open `index.html` in your browser
